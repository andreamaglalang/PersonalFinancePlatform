# Consolidation decisions

The isolated branch starts at `integration/owli-platform` (`0731268`), which contains the Hermes handoff (`12fbf9a`) and merged Android budgets, currency, reports, FX, MVC administrator, backend reports/FX/Hangfire and admin-username feature lines. Every local PersonalFinance repository/worktree was inspected. Full branch names, original heads and dirty-file inventories are in [SOURCE_INVENTORY.json](SOURCE_INVENTORY.json). Original working directories and uncommitted files were left intact; no stash, reset, checkout, cleanup, database operation or deployment restart was used.

| Component | Selected source |
| --- | --- |
| MVC member and administrator site | `PersonalFinancePlatform-MVC-Tier0` at `fcb1685` plus its current tracked and new application/test source: member dashboard, activity/editing, budgets, categories, goals/bills, notifications, reports, account/currency, registration and UI checks |
| Android | Integrated Android from `PersonalFinancePlatform-OWLI` at `0731268` plus its current application, JVM and instrumentation source: protected persistent sessions, offline recovery, live account/plan, currency preferences, rate review and report refinements |
| API and finance persistence | Integrated backend plus MVC Tier0's current authentication transactions, bill-payment date fixes, snapshot/configuration, migration 5 and Hangfire isolation/scheduling |
| Account API/security | OWLI current `/api/account` service/controller, JWT security-stamp validation, token issuer, transport middleware and authentication tests; MVC `/api/auth/me` and `/api/auth/change-password` retained for compatibility |
| Administrator provisioning | Main working folder's current explicit username implementation and offline tests, layered on integrated source |
| Alternative jobs / SQL checks | Main working folder's untracked automation classes and SQL-test projects retained; no SQL test was activated |

`deployment/owli-server`, backend, FX, reports, MVC review, Hermes, Android budgets/currency/FX/reports worktrees were clean at inspection. Their compatible feature history was already integrated. The original Android folder is based on `36b6a9f` and has another, divergent set of live bills/savings/notifications and auth/cache changes. Blindly replacing integrated OWLI with it would lose the newer reports/currency/session integration. Its tracked and new Android source changes are preserved in [ANDROID_ALTERNATIVE_WIP.patch](ANDROID_ALTERNATIVE_WIP.patch), relative to `36b6a9f`, for selective porting. It is an inert recovery artifact, not applied to the active source and not certified as compatible. Its stale backend copy was not overlaid. The old `wip/android-worktree-snapshot-20261121` branch remains reference-only.

The alternative jobs are deliberately not registered with the active worker. They use different recurring IDs and SQL transaction behavior; a maintainer must choose and test one family before activation. The selected backend preserves the stable existing IDs and dedicated-storage validation.

The GitHub refresh also discovered `origin/handoff/owli-visual-parity-20261122` at `faa7b17` (not previously present in local refs). It implements a competing MVC `/Personal` portal, platform administration/content/support APIs, and platform journal/content migrations (`20261122090000`, `20261122091331`). It removes substantial integrated Android, FX, recurring-bill and Hangfire source. This handoff therefore retains its history through a history-only merge rather than applying its replacement tree. Its source remains recoverable in a normal clone with `git show faa7b17:<path>` or a separate worktree at `faa7b17`. Do not apply its platform migrations to the selected model: the active schema has five migrations and no platform content entities. Port the platform/admin features and their tests/model changes as a reviewed feature branch. The later local MVC Tier0 member implementation is the selected active portal. The history-only merge explicitly preserves competing source, not a claim that its platform features are activated here.

The preserved standalone SQL harnesses now use synthetic `OWLI-FIXTURE` identity, SID and path declarations in place of the owner's machine identifiers. These remain offline declarations, never authorization or a configuration for a real machine. Their historical test targets need redesign before SQL execution. No integrity hash was refreshed to grant live execution.

Profile/password DTO names were separated internally (`AccountUpdateProfileRequest` / `AccountChangePasswordRequest`) because Android requires profile versions and password confirmation while MVC's older auth routes have different JSON shapes. HTTP shapes and both routes remain available; sharing one C# type would break clients. MVC's password transaction changes and Android's security-stamp token checks are both retained.

Excluded material: private development JSON, user secrets, `.env` values, original localhost certificate, private keys/signing material, SDK paths, databases/backups, device state, generated APK/build/test output, runtime probes, personal operational evidence, and one-time Python source-edit scripts. Original excluded material remains in its original location. No financial database or accounts are needed for a clean clone. Public test fixtures use synthetic data.
